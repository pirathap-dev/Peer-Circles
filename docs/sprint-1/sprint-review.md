## Sprint Goal
The goal of Sprint 1 was to implement and integrate the core user authentication and profile management functionality for the Peer Circles application. This included user registration, secure login, logout/session management, and viewing and updating user profile information.

## Completed Stories
- US-01 — Register an account
- US-02 — Login securely
- US-03 — Log out
- US-04 — View and update profile

## Incomplete Stories
- None

## Demonstration

The team demonstrated the completed Sprint 1 functionality, including:

1. Creating a new user account through the registration page.
2. Logging in using valid user credentials.
3. Accessing authenticated user functionality after login.
4. Viewing the user's profile information.
5. Updating profile information.
6. Logging out from the application.
7. Verifying that the authenticated session is terminated after logout.

The team also demonstrated the integration between the frontend, backend APIs, authentication/session handling, and database.

## Feedback
- The implemented authentication flow was reviewed and considered functional.
- Registration and login flows were verified successfully.
- Logout and session handling were reviewed.
- Profile viewing and updating functionality was demonstrated successfully.
- Testing results were reviewed, and the completed Sprint 1 functionality was accepted.
- Further improvements and additional features can be addressed in upcoming sprints

## Decisions
- All four Sprint 1 user stories are considered completed.
- The completed authentication and profile functionality will be used as the foundation for subsequent features.
- Any minor UI improvements or additional validation identified later will be addressed in future sprints where appropriate.
