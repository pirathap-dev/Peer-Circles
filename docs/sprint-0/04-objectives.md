# Peer Circles — Project Objectives

## 1. Primary Objective

To design and develop a functional mobile peer-support platform using Scrum that allows users to access and participate in peer-support communities.

---

## 2. Specific Objectives

### Objective 1 — Authentication

Implement secure user registration, login and logout functionality.

### Objective 2 — Profile Management

Allow users to view and update their basic profile information.

### Objective 3 — Support Groups

Allow users to discover, search and view available peer-support groups.

### Objective 4 — Community Participation

Allow users to join support groups and participate in group discussions.

### Objective 5 — Content Interaction

Allow group members to create discussion posts and comment on existing posts.

### Objective 6 — Privacy

Incorporate privacy-conscious functionality into the platform.

### Objective 7 — Quality Assurance

Perform functional, UI, API, integration and regression testing to identify and resolve defects.

### Objective 8 — Agile Development

Demonstrate Scrum practices through Sprint Planning, Daily Scrums, Sprint Reviews, Sprint Retrospectives, backlog management and iterative development.

### Objective 9 — Team Collaboration

Ensure that all four team members make identifiable contributions to development, testing, Scrum activities and project documentation.

---

## 3. Success Measures

The objectives will be considered achieved when:

- Core user stories satisfy their acceptance criteria.
- The application can execute successfully.
- Critical functionality passes testing.
- Major defects are resolved.
- Sprint increments are demonstrated.
- Scrum activities are documented.
- GitHub contains evidence of team collaboration.
- Individual team contributions can be identified.
