# Peer Circles — Project Scope

## 1. In Scope

The following functionality is included within the planned Peer Circles product scope.

### Authentication

- User registration.
- User login.
- User logout.
- Basic authentication/session management.

### User Profile

- View profile.
- Update profile information.

### Support Groups

- Browse support groups.
- Search support groups.
- View support-group details.
- Join a support group.
- Leave a support group where implemented.

### Community Discussions

- View group discussions.
- Create discussion posts.
- Comment on discussion posts.

### Privacy

- Privacy-conscious user participation.
- Privacy-related profile settings where implemented.
- Anonymous participation where supported by the product design.

### Communication

- Peer-to-peer messaging where implemented.

### Resources and Events

- Educational resources where implemented.
- Event information/notifications where implemented.

### Quality Assurance

- Functional testing.
- UI testing.
- API testing.
- Integration testing.
- Regression testing.
- Defect reporting and verification.

---

## 2. Out of Scope

The following are outside the scope of the project:

- Professional medical diagnosis.
- Emergency medical services.
- Emergency/crisis intervention.
- Video consultations with medical professionals.
- Online payment processing.
- Insurance processing.
- Prescription management.
- Direct medical treatment.
- Large-scale production deployment.
- Advanced artificial intelligence diagnosis or therapy.

---

## 3. Scope Prioritization

The team will prioritize the core user journey first.

### Must Have

- Registration
- Login
- Logout
- Profile
- Browse groups
- Search groups
- Group details
- Join group
- Discussions
- Create posts
- Comments

### Should Have

- Privacy settings
- Anonymous participation
- Messaging

### Could Have

- Educational resources
- Events
- Notifications

Features will be prioritized according to user value, complexity and available development time.
